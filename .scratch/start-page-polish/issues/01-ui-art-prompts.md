# 01: 开始页三张图的出图需求

**What to build:** 交付一份给美术的《开始页出图需求》，让三张图——标题艺术字、按钮底图（正常 / 按下）、最高分奖杯图标——可以被独立产出、直接交付，并且在交付前就与代码解耦（美术不必问任何规格问题）。这是整件事的关键路径起点：文档一交付，出图就能开始。

**Blocked by:** None (can start immediately)

**Status:** done

- [x] 三张图的画幅、导出倍率、透明通道要求、四周透明留白、是否允许自带阴影 / 外发光，逐项写清
- [x] 标题艺术字标明：五字横排、设计尺寸与导出尺寸、**四周留白**，并说明"图上有阴影就没法调光影"
- [x] 按钮底图标明：需要**两态（正常 / 按下）**、按下态与正常态的差异要求、四角装饰必须压在边角一定像素范围内、中间区域必须是可拉伸的均匀纹理（为九宫格做准备）
- [x] 奖杯图标标明：透明底、尺寸、配色与标题金色的色族关系
- [x] 提供中文与英文两版**可直接复制**的提示词
- [x] 收图检查清单包含历史教训条目：无水印（含生成工具水印）、无设备界面元素（状态栏 / 电量 / 信号）、无文字乱码、色调与现有背景统一
- [x] 检查清单含一条通用动作：把图缩到 720×1280 看一眼再决定是否重出
- [x] 写明交付路径与文件命名，并说明"同名覆盖文件即生效，不需要改代码、不需要回编辑器接线"
- [x] 写明程序化 / 文字兜底的存在：图未到位期间页面照常可验收，不阻塞开发
- [x] 文档格式与既有的背景出图需求文档一致，放在同一处文档目录下
