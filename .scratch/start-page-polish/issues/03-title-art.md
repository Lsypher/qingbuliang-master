# 03: 标题艺术字（含兜底与窄屏等比缩放）

**What to build:** 开始页的标题从系统字体文字换成有设计感的艺术字图片：宽屏上保持设计尺寸不变形，窄屏（比 9:16 更窄的全面屏与拖窄的桌面窗口）上等比缩小到完整可见、绝不被切边；图片还没交付或加载失败时显示文字兜底，页面不开天窗。这一票同时建立本次唯一的自动化接缝——标题缩放的纯计算。

**Blocked by:** 02（复用底座：圆角绘制与界面图片加载入口）

  - 场景默认态是"兜底文字在场、图片节点隐藏"：图没交付/加载失败时页面不开天窗。
  - 顺手还原了保存场景时编辑器回写的 Canvas 自动布局噪音（`_lpos` 80/920 → 360/640、内容尺寸 160×1840 → 720×1280），本次场景 diff 里只有标题这一处真正的改动。
- `assets/scripts/ui/startPageLayout.ts`（新增）：本次唯一的自动化接缝，**不 import 引擎**。
  - `fitTitleWidth(visibleWidth)`：可见宽度 ≥ 560 保持设计宽 560；小于 560 收窄到"可见宽度 − 两侧各 60"，只缩不放。
  - `fitTitleScale(visibleWidth)`：配套的**等比**缩放系数（宽高同乘它），调用方直接 `setScale`，不必自己再除一遍设计宽度。
  - 一处理论死角做了退化：可见宽度窄到 240 以下时"两侧各 60"要吃掉比屏幕还多的宽度，硬套公式会算出 0 甚至负数（等于把标题藏起来）。这里让留白先让位——留白最多占可见宽度的 1/4，标题始终有地方站。**240 及以上与"两侧各 60"逐像素一致**，320 那一档结果不变。
- `assets/scripts/ui/StartView.ts`：标题接线。
  - `showTitle()` 二选一：取到图就显示图、取不到（未交付/文件坏）就显示兜底文字，切换只改 `active`；已经加载过（再次回到开始页）直接用缓存里的 frame，不等回调，免得闪一下兜底文字。取图走 02 票收口的 `loadSpriteFrame`。
  - `fitTitle()` 按 `fitTitleScale(visibleWidth())` 对**两套节点**同比缩放（谁在场都是同一个宽度），并挂进已有的 `canvas-resize` 重排。可见宽度的取数仍走 `uiFactory.visibleWidth()`，与玩法说明的收窄是同一个来源。
  - 兜底文字串改从 `TitleFallback` 取；标题文案仍在集中文案表里。
- `assets/scripts/config/strings.ts`：给 `title` 补了注记——它与艺术字图片上的五个字互为镜像，**改文案等同于重出一张图**。
- `assets/resources/art/ui/title-art.png.meta`：标题图按约定改成**不裁剪**（`trimType: none`，保留原始画布，避免五字被裁导致定位漂移）、**不参与自动图集**（`packable: false`）。
- `docs/art/ui-prompts.md`：把这条导入约定写进美术看的那份出图需求（只加 5 行），并说明连 `.meta` 一起覆盖最省事。
