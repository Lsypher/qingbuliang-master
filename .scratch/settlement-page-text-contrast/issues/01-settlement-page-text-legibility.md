# 01: 结算页压在背景图上的文字看不清

Status: done

**What to build:** 结算页的 7 处文字全部直接压在背景图上，自己没有任何底板——结算页不换背景，沿用上一局那张随机图（没开局时是开始页封面），而整屏压暗层 `backgroundDim` 的 alpha 早先被调成 0（见 `UI_COLOR.backgroundDim` 注释里那条既定取舍）。底一亮的几张（沙滩、白瓷砖墙、账本木台）就读不清。要让它们在任意一张背景上都读得清，做法与单局页那一票（`.scratch/round-page-text-contrast/`）完全一致：走 Label 自带的**字形描边**，不用叠两层偏移文字。

**问题（用户报，截图见 `.scratch/start-page-cover/evidence/03-result-page-no-regression.png`）：** `食饱未？` 与各项数值是白字压在亮沙滩上。这处在 `start-page-cover` 那票的「顺手发现」里记过一次，当时只动开始页、没一并处理。

**已定（沿用单局页那票的结论，不重新讨论）：**

1. 描边必须是**字形描边**（`enableOutline` + `outlineColor` + `outlineWidth`），不用"暗色垫底略偏移 + 亮色正文"——后者被用户否过（看着像两行字重在一起）。
2. 描边色统一 `(74,44,20)` 深暖棕，与开始页"最高分"、开摊按钮同一支（即 `UI_COLOR.textOutline`）。
3. 描边宽 = 字号 × 0.09（四舍五入，下限 2），与 `uiFactory.outlineWidthFor` 同一算式。
4. 压在背景上的**纯白一律收回**（结算页没有任何一块自带底板的地方）：标题、本局分数用暖金，完成订单、最高连击与按钮文字用暖米黄；**最高分原本就是暖金，不反向改回米黄**（见取舍记录 2）。
5. **不加半透明底板、不恢复整屏压暗**：与 `UI_COLOR.backgroundDim` 那条"不再整屏压暗，改用各元素自带底衬托住自己"的取舍保持一致。
6. **表现改动只落在场景**：结算页的骨架在场景里，骨架样式归编辑器——先例是开始页"最高分"改金色 + 加描边那次（改的同样是场景里的四个字段）。代码只在复审后同步过 `UI_COLOR` 的注释，行为零改动。

**Blocked by:** 无

### 取舍记录

1. **本局分数为什么给金色而不是暖米黄**：它是这一页的主角数字，与单局页倒计时数字同档（那一票的规矩是"金色只给必须第一眼看到的东西"）。标题（64 号）本来也是金色，一页两个金点：一个是名字，一个是比分。
2. **最高分保持金色**：这支金色是用户先前点名要的（`start-page-cover` 的「后续调整」），不反向改回米黄；它虽然也算统计行，但保留原色更贴合"没人要求改它"。
3. **破纪录那句的描边用 `textOutline` 而不是 `comboShoutOutline`**：结算页这行是**静态页面文字**，不是飘字；单局页那支深红近黑 `(70,16,0)` 是给飘在碗心的"够劲！"压场用的。橙字配深暖棕实测约 5.8:1，够用。
4. **按钮文字也算"压在背景上"**：`RestartButton` 上挂的 `cc.Graphics` 是空画板（场景里没有任何绘制路径，运行时也没人往里画），所以"再来一碗"没有底板，白字会被亮底吃掉——按正文处理。
5. **描边宽按字号等比而不是固定 3**：与单局页同一个算式，保持两页一致；64 号的标题落 6，是这一算式在最大字号下的自然结果。
6. **还原了编辑器回写的噪音**：保存时编辑器把开始页 `BestScore` 容器的 `_contentSize` 从 `154.909×55.44` 回写成 `160.909×61.44`（该值运行时不读，是编辑器里的"行盒"参考）。按 ADR-0002 的既有做法在文件里还原，本次 diff 因此只剩结算页文字。副作用照旧记一笔：编辑器那边这个值已在内存里，下次保存可能再出现。

### 2026-09-23：本票三条结论被 02 号票取代

用户随后要求把结算页标题与"再来一碗"都换成交付的底板图（见 `02-result-page-board-art.md`），本票以下三条随之失效：

1. 「压在背景上的纯白一律收回」→ 标题与按钮改回**白字**（可读性改由描边 + 底板共同承担）；
2. 「不加半透明底板」→ 两处补上**实底图**（不是半透明底板；`backgroundDim` 仍是 alpha 0）；
3. 「表现改动只落在场景、代码零行为改动」→ 新增了运行时兜底加载与两支描边色。

上面验收表里「纯白清零」一条即日起不再成立。本票其余结论仍然有效：字形描边（不用叠两层文字）、描边宽算式，以及其余 5 处文字的配色与描边。
