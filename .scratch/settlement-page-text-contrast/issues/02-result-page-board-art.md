# 02: 结算页标题与"再来一碗"改用交付的无字底板

Status: done

**What to build（用户两条指令，原文）：**

1. 「将结算页中原有的"食饱未？"文字元素替换为指定图片样式。使用本地图片文件"…/素材/结算页/食饱未.png"作为该视觉元素的底图，并将原文字样式调整为与图片中一致：字体粗壮圆润，白色字体，带有黑色描边。确保替换后的样式在结算页中正确显示并保持整体布局协调。」
2. 「给 再来一碗.png 按同样做法处理」

**关键事实（它决定了做法）：两张交付图都是"无字底板"**——`食饱未.png`（3360×1312）只有木牌，`再来一碗.png`（3296×1184）只有绿胶囊。用户附的效果图里那版"白字 + 深色描边"是**目标观感**，图里本身没有字。所以走 ADR-0013 那条路：**图当底板、文字仍由引擎渲染**，与 ADR-0011（开摊按钮的字烤在图里、文字节点停用）刚好相反。

**已定：**

1. 两处都拆成"底板 + 文字"两层兄弟节点（`Board` 在前、`Label` 在后）：兄弟顺序即绘制顺序。按钮那处还另有硬约束——`Sprite` 与 `Graphics` 都是 `UIRenderer`，引擎不允许挂同一节点（编辑器直接拒绝）。
2. 尺寸按素材比例**等比**、取原节点高度：标题 267.8×104.58（原 256×104.58，直接套会把木牌横向压扁 4.5%）、按钮 267.2×96（原 320×96，会压扁约 17%）。两块几乎同宽，这一页上下两块因此对在同一条中轴上。
3. 文字：两处都改成**白字 + 描边 + 加粗**。标题 50 号 / 描边宽 5 / 暖近黑 `#24160C`；按钮 40 号 / 描边宽 4 / 深绿近黑 `#1B3A0E`——描边各取自己底板的深色同族，不共用 `textOutline` 深暖棕。
4. 按钮的按下反馈从 NONE 改成 Button 的 SCALE 过渡 + 0.95（素材只有一张，没有按下态图可换）。
5. 两处底板共用 `ResultView.attachBoardArt` 的按文件名兜底加载；场景里都已接线（编辑器所见即所得）。
6. 素材入库 `assets/resources/art/ui/`；导入与场景约定收在 ADR-0013 的「结算页底板的导入与场景约定」一节（唯一权威落点）。

**Blocked by:** 无

### 与 01 号票的关系（旧结论被取代）

01 号票处理的是"文字压在背景图上读不清"，本票处理的是"给两处补上底板"——用户的新指令改变了前提，故 01 号票的三条结论自本票起不再适用：

| 01 号票原结论 | 现状 |
| --- | --- |
| 「压在背景上的纯白一律收回」（验收项：纯白清零） | 标题与按钮改回**白字**——可读性改由描边 + 底板共同承担 |
| 「不加半透明底板、不恢复整屏压暗」 | 两处补上**实底图**（不是半透明底板；`backgroundDim` 仍是 alpha 0） |
| 「表现改动只落在场景、代码零行为改动」 | 本次新增了运行时兜底加载与两支描边色 |

仍然有效的部分：字形描边（不用叠两层偏移文字）、描边宽算式，以及本页其余 5 处文字（`ScoreLine` / `OrdersLine` / `ComboLine` / `BestLine` / `NewRecordLine`）保持"暖金 / 米黄 + 深暖棕边"。

01 号票末尾把它没做的"按钮要不要补底板"推给"另一票"——就是本票。

### 未达成 / 已知偏差（用户可决定是否继续）

1. **"圆润"只是近似**：只加了 `isBold`，字体仍是系统 Arial（"粗壮"有、"圆润"到不了图上那种圆体笔画）。要像素级一致，得引入一份**授权明确**的圆体字体文件并登记许可（ADR-0001 的取材原则）；本次没有自带字体，故不做。
2. **描边不是纯黑**：标题用暖近黑 `#24160C`、按钮用深绿近黑 `#1B3A0E`。理由写在 ADR-0013 / 0014 与 `UI_COLOR` 的注释里（暖色底上纯黑显脏，冷绿底上暖棕边发浑）。要改回纯黑，只需改场景里那两个 `_outlineColor`。
3. **按钮白字压亮绿约 1.8:1**，可读性全押在描边上——与开摊按钮图上"白字压暖橙"是同一种做法；想更稳可把正文换成深绿近黑（约 6.7:1）。

- **数据**：场景改动经编辑器 `save_current_scene` 落盘，`git diff` 逐块核对；`Board` / `Label` 的 `layer`、`sizeMode`、帧 uuid、尺寸与文字字段都用脚本读回确认过。
- **静态**：`npm test` 121 条全绿（含本票新增的 13 条）；`npx tsc --noEmit` exit 0。
