# 错放时的中央"-3 秒"弹窗

## Problem Statement

错放（把订单不需要的配料拖进碗里）当前的反馈是屏幕边缘红闪、顶部倒计时旁飘出的"-3 秒"与配料弹回。飘字锚在顶部，玩家视线若停在碗上就会错过——而错放的代价（扣 3 秒）需要一个更抢眼、且落在视线中心附近的提示。

## Solution

错放瞬间在**碗内上部空档**（单局页 `(0, 140)`）弹出一张现成美术件（`assets/resources/art/ui/misdrop-penalty.png`：红底 + "-3秒" + 时钟图标），做轻微抖动与两侧残影，停留约半秒后淡出、节点自毁，整段约 0.9 秒。图形在准备过场期间预载，保证首次错放也能首帧显示。顶部那条"-3 秒"飘字保留，两处并存。

## 需求原文

### A. 功能新增（委托方原话）

> 当玩家错放物品时，在屏幕中央添加红色文字弹窗提示。弹窗图片素材路径为"C:\Users\nxm\Desktop\素材\错放\-3秒.png"。请评估此方案是否可行。若可行，请进一步实现为动画效果：加入轻微抖动与残影，使提示更醒目且不显突兀。请确保弹窗在错放动作触发后立即显示，并在设定时长后自动消失，同时不影响其他游戏交互，不覆盖页面其他文字内容。

两处选择题上委托方的答复（同样是需求的一部分）：

- **弹窗位置**：选「碗内上部空档 y≈140」——"视觉上仍居中偏上、一眼看到，且不压任何文字与图标，完全满足第 3 条约束"。（另一选项「严格屏幕正中 (0,0)」因会压住"空碗"或碗内图标被否）
- **顶部已有的"-3 秒"飘字**：选「两者都保留」。

### B. 缺陷修复（委托方原话）

> 这个弹窗的显示比例明显异常，似乎被非等比拉伸或放大了，与原始设计比例不符，尤其是高度方向被拉长。请检查弹窗的宽高比设置、缩放逻辑或响应式布局是否误用了固定高度、强制拉伸或错误的 transform 缩放，并提供修复方案使弹窗恢复原本比例。

## User Stories

1. 作为玩家，我想在错放时于屏幕中央看到一张醒目的"-3 秒"提示，这样即使视线停在碗上也不会错过自己刚被扣了时间
2. 作为玩家，我想让这个提示轻微抖一下、带点残影，这样它够醒目但不至于像突然蹦出来的硬块
3. 作为玩家，我想让提示自行消失、不用我去关，这样它不会一直挡着碗
4. 作为玩家，我想在提示出现的同一刻还能继续拖拽配料，这样一次错放不会打断我的手
5. 作为玩家，我想在误放「碗里已经有的同一种配料」时什么提示都不出现，这样手滑连点不会看到假警报
6. 作为玩家，我想让这张图的形状与美术给的一样（横向的红底条），这样它看起来不像被拉变形

## 未完成

- **比例异常的真正原因尚未定位。** 修复改成了按"图片内容矩形"取比例（语义正确，且对纹理尺寸变动免疫），但没取到运行时的实测数据——改代码后预览无法重载，本版编辑器不存在 `preview.stop/play/reload` 消息。实机截图量出弹窗红底比例约 1.08，而素材红底是 2.03，方向对得上"高度被拉长"，但按代码算出的 contentSize 应约 240×140，与实测不符，**差在哪里还没定位**。详见 `docs/adr/0010-misdrop-center-popup.md` 的 Consequences。
- **实机验收**：见同一条 ADR 的"人工验收"一节。
- **已知偏差**：弹窗纵带（约 [70, 210]）与出餐得分飘字（≈95 起）、连击喊话（≈225）在纵向重叠，碗上方没有能容下它的空档，物理上躲不开。需求 A 的"不覆盖页面其他文字"因此**只兑现了一半**：静态文字没被压，出餐浮层会叠。
