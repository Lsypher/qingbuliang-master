# 《清补凉大师》MVP 设计基线

本文件是 grilling 会话收敛后的设计基线：代码实现与验收都以本文件为准。领域术语以根目录 `CONTEXT.md` 为准，术语有冲突时以 `CONTEXT.md` 优先。

## 一句话

海南清补凉主题的拖拽配对 H5 小游戏：顾客下单，玩家把配料拖进碗里，凑齐即出餐，60 秒比分数。

## 范围

**做**：单局 60 秒的完整可玩闭环（开始页 → 单局 → 结算页）+ 最高分持久化 + web-mobile 构建产物。

**不做**（明确排除，别顺手加）：音频、关卡/波次、联网排行、多语言、人物骨骼动画、定制美术贴图（MVP 图标采用项目方自绘透明底 PNG）。

## 玩法规则

| 项 | 规则 |
|---|---|
| 单局时长 | 60 秒；正确出餐**不加时** |
| 顾客 | 一次一位；出餐后换下一位，过渡动画 ≤0.4 秒，**过渡期间暂停计时** |
| 订单 | 恰好 1 汤底 + 3~5 小料，从 12 格配料池随机 |
| 难度 | 0–20 秒 3 小料 / 20–40 秒 4 小料 / 40–60 秒 5 小料 |
| 匹配 | 顺序无关的集合匹配；凑齐即**自动出餐** |
| 放入方式 | 拖动（跟手、松手判定、碗高亮）+ 点按直接飞入 |
| 错放 | 扣 3 秒 + 弹回配料盘 + 断连击；碗中已有该配料时再拖入**不扣时** |
| 计分 | 每单 10 ×（小料数 + 1）；连击每单额外 +5、上限 +25（5 连封顶） |
| 背景 | 开始页用专属**封面图**（固定不随机，标题与副标题画在图里）；每局从背景池随机一张；纯视觉，不影响玩法 |

## 界面

- **布局**：竖屏 720×1280，`FitHeight`；三段式——顶部订单区 / 中部碗 / 底部配料盘
- **顶部**：倒计时数字 + 进度条（最后 10 秒变红脉冲）、分数、连击
- **订单卡片**：顾客 emoji 头像 + 汤底图标 + 小料图标行；已放入碗中的项打勾变暗，未满足的保持高亮（不另做差集面板）
- **碗**：显示已放入的配料图标，按放入顺序排列
- **配料盘**：12 格，每格手绘图标 + **中文短标签**（标签是识别主通道）
- **开始页**：一张整屏封面图，标题「清补凉大师」与一行「60秒限时配对」画在图里（见 `docs/adr/0004-start-page-cover-art.md`）；最高分；开始按钮
- **准备过场**：开始页／结算页 → 单局页之间的全屏过场，无按钮、不可交互；单局计时在它结束之后才开始（细节见 `.scratch/prepare-transition/spec.md`）
- **首局引导**：配料盘上方浮一行"把配料拖进碗里，凑齐即出餐"，首单出餐后消失
- **结算页**：分数、完成订单数、最高连击、破纪录提示、最高分、重开按钮
- **反馈**：错放屏幕边缘红闪 + 计时处飘"-3s"；出餐后碗清空

## 配料池（12 格）

- 汤底 3：椰奶、椰子水、红糖水
- 小料 9：红豆、绿豆、西米、芋圆、西瓜丁、芒果丁、通心粉、仙草冻、鹌鹑蛋

图标现采用项目方自绘透明底 PNG（文件名即 id，同名覆盖即换图），详见 `docs/adr/0001-asset-sourcing-and-licensing.md`。

## 文案风格

轻度海南味，**克制在 3~5 处**（如结算页"食饱未？"、连击"够劲！"、破纪录"老板娘都服了"），不做全篇方言。

## 技术约定

- 数据驱动：配料、难度曲线、计分规则、文案都写成 TS 配置，不写死在 UI 组件里
- 单一状态持有者 `GameSession` + `EventTarget` 事件总线；UI 组件只订阅渲染；不引第三方框架
- 目录：`assets/scripts/{config,core,game,ui}`（开发期的 `debug/` 自检目录已按 spec 要求于 12 号切片上线构建前删除）；美术资源放 `assets/resources/art/`（`backgrounds` / `ingredients`）——**必须放在 `resources` 下**才能按文件名动态加载：池子换图只换文件，代码与场景都不用动（08 切片的配料图标沿用同一约定）；音频 `assets/resources/audio/`（MVP 暂空）
- 最高分存 `sys.localStorage`；中文文案集中在 `strings.ts`；不引 i18n；字体用系统字体（不内嵌中文字体，控制包体）
- 素材来源逐个登记到 `CREDITS.md`；背景由用户提供，已是交付档位（无需占位）
- 代码标识符用英文，注释与文档用中文

## 验收清单

1. 打开见开始页并显示最高分；点开始进入单局
2. 60 秒倒计时正确；每局随机背景
3. 订单恒为 1 汤底 + 3~5 小料；难度三段按时间提升
4. 拖动与点按都能放入配料；汤底 / 小料判定正确
5. 集合匹配：放入顺序不同不影响出餐
6. 错放：-3 秒 + 弹回 + 断连击；重复拖入同一配料不扣时
7. 出餐自动触发，得分与连击数值正确
8. 结算页数值正确、破纪录有提示、重开正常
9. 最高分持久化，刷新浏览器不丢
10. 手机浏览器（Chrome / Safari 移动版）可玩，无横向滚动、元素不被裁切
