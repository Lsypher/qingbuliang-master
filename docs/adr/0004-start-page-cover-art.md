# 开始页的标题与副标题烤进整屏封面图

**决定**：开始页的底图换成一张整屏**封面图**（`assets/resources/art/backgrounds/start-page.png`，1600×2848），标题艺术字「清补凉大师」与副标题「— 60秒限时配对 —」**画在图里**；场景里 `TitleArt`、`TitleFallback`、`Subtitle`、`SubtitleBox`、`HowToPlay` 五个节点全部删除，`StartView` 只再管最高分行与开摊按钮。

**为什么**：整屏交付的美术能给出代码拼不出来的构图——大碗居中、椰林沙滩、文字与画面的光影是一体的；而把文字拆成节点摆，就得另出一张透明底艺术字、再给副标题垫一块底框、再单独定位一行说明，最后仍是"贴上去的字"。取舍是自觉的：**这一屏的文案从此由美术决定**。

## 代价与边界

- **改开始页文案 = 重出封面图**。`config/strings.ts` 里不再有 `title` / `subtitle` / `howToPlay` 三个键；文案表管不到这一屏，也不该再往里加。
- **「60 秒」这个数字进了图**：动 `docs/design/mvp-spec.md` 的单局时长就要跟着重出封面图。这是文字烤进图的直接后果，不是漏改。
- **窄屏是裁掉两侧，不是压扁**：背景节点固定 720×1280，FitHeight 的窄屏只看得见中间约 590 宽，所以图上居中的文字不会被拉伸变形，被裁掉的是两侧的椰树与摊位。图的比例 1600×2848（0.5618）与设计的 9:16（0.5625）差 0.12%，满屏拉伸的形变可忽略。
- **开始页不再承担"教怎么玩"**：图上没有"把配料拖进碗里，凑齐即出餐"，操作说明只由单局页的首局引导（`GuideHint`，首单出餐后消失）承担。开始页那一屏只负责"一眼看出是什么游戏、值不值得点"。
- **最高分行仍留在场景里**，并保住"最高分位数会变、整行必须按实测文字宽重算居中"这条既有约束（见 ADR-0002 的 05 号例外）。

## Considered Options

- **整屏封面图（选中）**：构图最完整、交付链路最短（美术给一张图即完工），代价是文案不可改。
- **保留元素化骨架、只换背景图**：文案仍归 `strings.ts`、仍可本地化，但做不出"文字与画面一体"的封面感——而这正是本次要的。
- **两者并存**（封面图之上仍摆一份文字节点）：会在图上叠一层重复的字，直接排除。

## Consequences

- 开始页的静态骨架从七个节点缩到两个（最高分行 + 开摊按钮）；`StartView` 随之删掉标题缩放、副标题底框、玩法说明收窄的全部逻辑，`startPageLayout.ts` 只剩最高分那一行，`tests/titleArt.test.ts` 换成 `tests/startPageSkeleton.test.ts`。
- `assets/resources/art/ui/title-art.png` 随之弃用并删除（登记同步退出 `CREDITS.md`）；`docs/art/ui-prompts.md` 保留它的需求段作墓碑，说明已被封面图取代——否则下一个美术还会照它出图。
- ADR-0002 里"开始页骨架进场景"的**内容清单**部分被本条取代；"只有开始页进场景、其余页维持运行时装配"这个取舍本身仍然有效。
