# 素材来源与授权策略

美术资源全部取自授权明确的开源渠道（CC0 / MIT / CC-BY）或用户自备原创，逐个登记来源到 `CREDITS.md`，授权不明的国内素材站（千图、觅元素等）一律不用。配料图标现采用项目方自绘透明底 PNG（文件名即 id，同名覆盖即换图），不再依赖开源 emoji；背景图由用户提供——已搜索确认开源站以欧美题材为主，没有海南骑楼 / 黎锦题材的现成背景；MVP 不做音频。允许使用 CC-BY 素材，代价是必须登记到 `CREDITS.md`（游戏内不另设致谢）。

## Considered Options

- **AI 生成**：风格一致性需反复抽卡、透明背景需抠图，且生成物版权归属在国内尚不明确。留作背景图的后备手段。
- **程序化绘制（Cocos Graphics）**：适合黎锦这类几何纹样，但不适合写实食物图标，观感与工期都不占优。
- **CC0 / MIT / CC-BY 开源素材**：来源可追溯、可商用。选中。
- **国内素材站**：授权条款不清晰，明确排除。

## Consequences

- 图标为项目方自绘透明底图；换图靠文件名稳定（文件名即配料 ID）即可，无需改代码。
- 交付物必须包含署名，不能只在代码注释里提一句。
- 背景图依赖用户交付，开发期间用程序化占位，不阻塞。
