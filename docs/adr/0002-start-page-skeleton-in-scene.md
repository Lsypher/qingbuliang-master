# 开始页的静态骨架放在场景里，其余页维持现状

> **内容清单部分已被 ADR-0004 取代（2026-09-22）**：开始页的标题（艺术字与文字兜底）、副标题与其圆角底框、玩法说明这五个节点已经删除，改为烤进整屏封面图。本条剩下的、仍然有效的是"只有开始页进场景、其余页维持运行时装配"这个取舍本身，以及下面两条"例外"里对最高分行与开摊按钮的约定。

**决定**：开始页的静态骨架作为节点摆在 `assets/scenes/main.scene` 里——标题（艺术字或兜底文字）、副标题与其圆角底框、玩法说明、最高分行、开摊按钮，位置与尺寸都在编辑器里调、所见即所得。单局页与结算页的装配方式**一行不动**，维持现状。

**为什么**：愿意动场景的唯一动机是"开始页要反复调版面"。这次升级的重点就是把这一屏从代码拼装的调试页变成有设计感的封面，之后还要反复试间距与层级；骨架进了场景，改一次间距就不必再跑一次预览。

**为什么不顺手把另外两页也迁进来**：单局页是动态布局（拖拽跟手、随机图标、计时重排），它的节点内容本来就由各视图组件在运行时装配，迁进场景收益低，而"踩坏已经跑通的自适应逻辑"的风险高；结算页是纯展示页，骨架已经在场景里、也没有反复调版面的需求，不必动。这条不一致是自觉取舍，不是遗留疏忽。

## Considered Options

- **只把开始页的静态骨架放进场景**：选中。调版面最频繁的一页拿到所见即所得，其余两页零风险。
- **三页的静态部分全放进场景**：一致，但单局页的动态内容（订单卡图标行、碗中图标、拖动幽灵、进度条填充）无论如何都得运行时装配，最后仍是混合形态；代价是要重写一遍已经验收过的自适应逻辑。
- **全部维持运行时装配**：最一致，但开始页每改一次间距就要跑一次预览，与本次升级的动机直接冲突。

## Consequences

- `assets/scenes/main.scene` 开始承载开始页的版面：标题艺术字、副标题底框、最高分行、按钮底图都是场景节点，容器位置由编辑器调。
- 场景里的文字仍是"摆版预览值"：页面每次显示都由视图组件从 `config/strings.ts` 重刷一遍，文案表依旧是唯一文案来源。**（2026-09-22 起开始页是例外：它的标题与副标题画在封面图里，不归文案表管，见 ADR-0004）**
- 编辑器保存场景时会按当前 Game View 画幅回写 Canvas 的自动布局值（位置与内容尺寸）。每次保存后都要检查 diff，别把这类噪音夹进提交。
- 表现层因此是混合形态：有的界面在场景里摆，有的在代码里装。新增界面组件时写清自己属于哪半边——`StartView` / `ResultView` 只改场景骨架上的文字，`HudView` / `OrderCard` / `BowlView` / `IngredientTray` / `GuideHint` 自己装配节点——避免后来者把场景里那份当成遗漏。
- **例外（05 号票，自觉重开上面那条"只改文字"）**：最高分那一行**行容器内部**的两个元素（奖杯图标与文字）由 `StartView` 在运行时摆位——最高分的位数会从 1 位变到多位，"整行居中"必须按文字的**实际**宽度每次重算，在编辑器里把两者的位置摆死，位数一变整行就会偏。行容器自身的位置仍在场景里（**−430**，2026-09-22 随封面图换新由 −330 下移），开摊按钮的位置也依旧由编辑器调。这是"场景里摆骨架"与"按运行时数据重排"之间最小的一处让步，不是把版面搬回代码。
- **例外（06 号票，同一条的又一次让步）**：开摊按钮有四件事由 `StartView` 在运行时做，都不属于"只改场景骨架上的文字"——① 底图按文件名取（正常 / 按下两态，场景里只留一个空的 Sprite 槽位，同名覆盖即换图）；② 按下时缩到 0.95（一个按钮只有一种过渡方式，换图已经占用了 Sprite 过渡，缩放只能自己补）；③ 底图未交付 / 加载失败时用程序化木色圆角面板占位（占位节点在场景里，面板本身由代码经 `uiFactory.paintRoundPanel` 画）；④ 九宫格边距写在底图的 `.meta` 里，属资源数据、不是场景数据。按钮**该在场景里的东西仍在场景里**：位置（**−545**，2026-09-22 随封面图换新由 −490 下移）、尺寸 360×140、九宫格 Sprite、两态过渡方式、文字描边都由编辑器所见即所得地调。
  > **2026-09-23 被 ADR-0011 部分取代**：底图换成自带"开始游戏"的胶囊按钮后，按钮不再走九宫格（改整图拉伸）、尺寸改为 **240×86**（取原图尺寸，设计像素 1:1 不放大），按钮文字也不再由 `StartView` 刷——场景里的文字节点是**停用**的。本例外的 ①②③ 仍然有效（底图运行时装、按下缩放自己补、占位底由代码画），④ 与"文字描边由编辑器调"两条随九宫格和文字节点一起失效。
- 三页仍在同一场景里用 `active` 互斥切换；切页广播与背景层的响应方式都不变。
