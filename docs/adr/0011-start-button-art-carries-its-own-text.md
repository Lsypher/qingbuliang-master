# 开摊按钮的字烤进底图，图片整图拉伸

**决定**：开摊按钮的底图换成一张**自带"开始游戏"四个字**的胶囊按钮图（`assets/resources/art/ui/start-button.png`，240×86；`start-button-pressed.png` 是同一个文件）。随之三处改动：场景里 `StartButton/Label`（"开摊"文字节点）**停用**、`StartView` 不再往按钮写文字；按钮的 Sprite 从**九宫格（SLICED）改回整图拉伸（SIMPLE）**；节点尺寸改为原图的 **240×86**（设计像素 1:1，不放大），位置仍在 `(0, −545)`。

**为什么**：交付的素材把文字画进了图里，而本仓库原来的规矩是"文字由引擎作为子节点叠在底图上"（`docs/art/ui-prompts.md` 图 2 的"文字"一行）。两条路只能选一条：

- 留着文字节点：图上的"开始游戏"上面再叠一层"开摊"，糊成一团；
- 停用文字节点：按钮文案从此由美术决定——与 ADR-0004 把标题与副标题烤进封面图是同一个取舍。

选后者。同一张素材还逼掉了九宫格：图上的字横跨画面正中，九宫格的中段横向拉伸会把字拉长，所以只能整图拉伸——而整图拉伸要不变形，节点就必须与原图同比例，**直接取原图的 240×86 最省事：既不变形，也不放大**（放大只会让这张 240px 宽的图更软）。代价是按钮比旧木牌小一圈（占屏宽从 1/2 降到 1/3），想更大就重出更大的图。

## 代价与边界

- **改按钮文案 = 重出底图**：图上写的是"开始游戏"，所以 `STRINGS.startButton`（"开摊"）不再上屏，只作**旧文案的墓碑**留档（ADR-0004 是把标题那三个键**删掉**；这里保留，是因为按钮日后可能换回无字底图、文字节点还要复活），文案表管不到这个按钮。
- **按钮图不能做九宫格**：想恢复九宫格，得先出一张**不含文字**、且四角装饰收在 `left ≤ 180 / top ≤ 70` 以内的图（两条硬约束见 `docs/art/ui-prompts.md` 的"九宫格切边"一行）。
- **按下态是同一张图**：素材只交付了一张，按下时不再换图，反馈只剩"缩到 0.95"——这条一直由 `StartView` 自己接在触摸事件上，本次未动。
- **文字节点留在场景里但停用**：`tests/startPageSkeleton.test.ts` 有一条用例锁住"它必须是停用的"，启用回来就会叠字。
- **窄屏不需要额外收窄**：按钮 240 宽，`FitHeight`（设计分辨率 720×1280）下比 9:16 更窄的常见画幅也只看得见约 590 设计像素宽，居中的按钮两侧仍各余约 175，不会被裁、也不会被压扁。
- **"不放大"是设计像素级的**：节点 240×86 与素材像素一一对应，画布缩放为 1 时屏幕像素也是 1:1；真机上 `FitHeight` 仍会整体缩放画布（如 1080×1920 的屏约 1.5 倍），要在这类屏上仍然像素级清晰，得出一张更大的图（比如 480×172）再把节点改成 480×172。
- **交互一行未动**：点击仍走 `GameRoot` 上指向同一个按钮节点的引用，进入单局页那条路径（含准备过场）不变。

## Considered Options

- **图片自带文字 + 停用文字节点（选中）**：完全按素材呈现，改动最小，与 ADR-0004 的处理方式一致。
- **让美术补一张无字底图**：能保住"文案归 `strings.ts`"与九宫格，但素材不在手上，且用户要的就是这张图。
- **保留文字节点、让它叠在图上的字之上**：直接叠字，排除。
- **维持九宫格**：会把图上的字横向拉长，排除。
- **按比例放大到 360×129**：按钮更有存在感，但 240px 宽的素材要放大约 1.5 倍，高分屏上更软，且九宫格方案已不可用（没有中段平纹）、放大也换不回任何清晰度。
- **保持旧设计稿的 360×140 铺满**：图被纵向拉长约 9%（圆角略变椭圆），且 1.5 倍放大。仅为对齐一个写在旧设计稿里的数值，不值得让交付图既变形又变软。

## Consequences

- `CREDITS.md` 的按钮登记与 `docs/art/ui-prompts.md` 图 2 同步更新：原"木牌 + 无文字 + 九宫格 843/328"的需求作废，只留作历史记录。
- 两张底图的 `.meta` 九宫格边距清零（`borderTop/Bottom/Left/Right = 0`），尺寸与裁剪矩形改为 240×86；`uuid` 不变，所以场景里的 Sprite 引用与"同名覆盖即换图"这条约定都不受影响。
- ADR-0002 的 06 号例外里"按钮文字保持为子节点、仍来自集中文案表"与"九宫格边距写在 `.meta`"两条被本条取代；该例外的其余部分（底图运行时装、按下缩放自己补、占位底由代码画）仍然有效。
- 占位底（底图缺失时的程序化木色面板）圆角由 16 提到 **28**——直接取原图量到的圆角半径，按钮按 1:1 显示，缺图时的占位底与真底图形状一致。
